Privacy and data

Is what I save private?

Yes. Your links, collections, tags and notes are stored only on your phone. Linked has no account and no cloud sync.

Does Linked use the internet?

Only to fetch a link's title and picture when you save it. The web address you saved is sent to a preview service for that, and nothing else about you is sent. Everything you have already saved works without a connection.

How do I move my links to a new phone?

Open the Security tab, tap Export JSON and save the file. On the new phone, install Linked and use Import JSON.

Can I lock the app?

Yes. Set a PIN in the Security tab and Linked asks for it each time you open the app.

I deleted a link by mistake. Can I get it back?

Check the Recycle Bin in the Security tab.

Everyday use

How do I save a link?

In any app, tap Share and choose Linked. You can also paste a link with the + button inside the app.

What is a collection?

A folder for related links, with its own name, colour and icon, such as Design, Recipes or Travel. A link can sit in one collection and carry as many tags as you like.

Why do some cards have no picture?

Some sites don't publish a preview picture, so Linked shows a coloured card with the title instead.

What does the open count mean?

How many times you've opened that link from Linked. Sort by Most opened to see what you actually go back to.

What does unread mean?

A link you've saved but never opened. Filter by Unread to clear your backlog.

General

Is Linked free?

Yes, Linked is free to download from Google Play.

Does it show ads?

No. There are no ads and no third-party tracking.
