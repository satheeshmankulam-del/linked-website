What Linked does

Saving

Add a link without leaving the app you're in.

  • Share any link to Linked from your browser, WhatsApp, YouTube or Instagram
  • The title and picture are fetched automatically
  • Pick a collection and tags as you save
  • Add a personal note about why you saved it
Library

Everything you've saved, laid out to browse.

  • Cards with pictures, in a two-column layout
  • Collections with their own colour and icon
  • Tags across collections
  • Filters for unread links and this week's saves
Finding

Get back to a link in seconds.

  • Search by title, site or note
  • Sort by newest, oldest, unread first, most opened or A to Z
  • Each card shows how many times you've opened it
  • Unread links stay marked until you open them
Dashboard

A quick look at your collection.

  • Total links, collections, unread and this week
  • A nudge to revisit your oldest unread link
  • Recently saved, in a compact list
Security and data

Private by design.

  • No account and no sign-up
  • PIN lock for the app
  • Export a JSON backup and restore it anytime
  • A recycle bin for links you delete by mistake

Common questions

Is what I save private?

Yes. Your links, collections, tags and notes are stored only on your phone. Linked has no account and no cloud sync.

Does Linked use the internet?

Only to fetch a link's title and picture when you save it. The web address you saved is sent to a preview service for that, and nothing else about you is sent. Everything you have already saved works without a connection.

How do I move my links to a new phone?

Open the Security tab, tap Export JSON and save the file. On the new phone, install Linked and use Import JSON.

Can I lock the app?

Yes. Set a PIN in the Security tab and Linked asks for it each time you open the app.
